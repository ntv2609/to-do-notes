# MILESTONE 0 (M0): KHỞI TẠO DỰ ÁN & KHUNG NỀN TẢNG

## HƯỚNG DẪN BẠN TẠO PROJECT TRONG ANDROID STUDIO QUAIL 4 (LÀM TRƯỚC STEP M0-S1)

Trước khi chạy Step `M0-S1`, bạn hãy mở **Android Studio Quail 4 | 2026.1.4 Patch 1** và thực hiện đúng các bước sau:
1. Chọn **New Project** -> Trong mục **Phone and Tablet**, chọn mẫu **Empty Views Activity** (biểu tượng có chữ XML/Views, **KHÔNG** chọn Empty Activity mặc định của Compose) -> Bấm **Next**.
2. Điền thông tin:
    - **Name:** `TodoNotes`
    - **Package name:** `com.vinhnt.todonotes`
    - **Save location:** Thư mục dự án trên máy của bạn
    - **Language:** Chọn **Java** (bắt buộc)
    - **Minimum SDK:** Chọn **API 26 ("Oreo"; Android 8.0)**
    - **Build configuration language:** Chọn **Groovy DSL (`build.gradle`)** hoặc **Kotlin DSL (`build.gradle.kts`)** tùy mặc định của bạn (sau khi tạo xong, dùng script `gop_code.py` gom các file gradle gốc gửi cho tôi ở `M0-S1` để tôi giữ nguyên đúng chuẩn DSL máy bạn đang dùng).
3. Bấm **Finish** và đợi Android Studio tải/đồng bộ Gradle lần đầu thành công.
4. Mở Terminal trong thư mục dự án, khởi tạo Git:
   ```bash
   git init
   git add .
   git commit -m "chore: initial Android Studio Java project template"
   ```
5. Đặt 2 script `gop_code.py` và `tach_code.py` của bạn vào thư mục gốc dự án, tách các file `docs/SPEC.md`, `docs/DECISIONS.md`, `AGENTS.md`, `docs/plan/*.md` vào dự án.

## STEP M0-S1: Cấu hình Gradle, AndroidManifest, Tiện ích nền tảng (`AppExecutors`, `DateTimeUtils`, `ValidationUtils`) & Unit Test đầu tiên

- **Mục tiêu 1 câu:** Cấu hình thư viện Room, Lifecycle, Material 3, ViewBinding vào file build của module `app`, thiết lập các hằng số mô hình dữ liệu (`Priority`, `TaskCategory`, `SubtaskItem`) và các lớp tiện ích cốt lõi kèm bộ JUnit Test đầu tiên.
- **Step phụ thuộc:** Đã tạo xong project trống `com.vinhnt.todonotes` trong Android Studio.
- **Chế độ khuyến nghị:** **Chat thường** (để kiểm tra khớp tuyệt đối cấu hình `build.gradle` hoặc `build.gradle.kts` của Android Studio Quail 4).
- **File cần gom để đính kèm:**
  ```bash
  python gop_code.py settings.gradle settings.gradle.kts build.gradle build.gradle.kts gradle/libs.versions.toml app/build.gradle app/build.gradle.kts app/src/main/AndroidManifest.xml
  ```
- **File sẽ tạo/sửa (10 file):**
    - `app/build.gradle` (hoặc `app/build.gradle.kts` + `gradle/libs.versions.toml` tùy hiện trạng file bạn gửi)
    - `app/proguard-rules.pro`
    - `app/src/main/java/com/vinhnt/todonotes/util/AppExecutors.java`
    - `app/src/main/java/com/vinhnt/todonotes/util/DateTimeUtils.java`
    - `app/src/main/java/com/vinhnt/todonotes/util/ValidationUtils.java`
    - `app/src/main/java/com/vinhnt/todonotes/util/SubtaskJsonHelper.java`
    - `app/src/main/java/com/vinhnt/todonotes/data/model/Priority.java`
    - `app/src/main/java/com/vinhnt/todonotes/data/model/TaskCategory.java`
    - `app/src/main/java/com/vinhnt/todonotes/data/model/SubtaskItem.java`
    - `app/src/test/java/com/vinhnt/todonotes/util/ValidationAndHelperTest.java`
- **Tiêu chí nghiệm thu (Given / When / Then):**
    - **Given:** Dự án vừa được tách code từ `M0-S1` và bấm "Sync Project with Gradle Files".
    - **When:** Chạy lệnh `.\gradlew.bat testDebugUnitTest` trong Terminal.
    - **Then:** Gradle đồng bộ không lỗi; toàn bộ các bài test kiểm tra tiêu đề rỗng, độ dài chuỗi, thời gian nhắc nhở trong quá khứ, và parse/serialize JSON công việc con trong `ValidationAndHelperTest` đều PASS 100%.
- **Cách kiểm thử:**
    - Lệnh Gradle:
      ```bash
      .\gradlew.bat testDebugUnitTest
      .\gradlew.bat assembleDebug
      ```
    - Kiểm tra thủ công: Bấm biểu tượng con voi **Sync Project with Gradle Files** trên thanh công cụ Android Studio, đảm bảo tab Build hiện tích xanh.
- **Rủi ro & Điều dễ sai:**
    - Android Studio Quail 4 có thể mặc định dùng Version Catalog (`gradle/libs.versions.toml`) và `app/build.gradle.kts`. Việc bạn đính kèm file gradle hiện tại giúp giữ nguyên đúng cấu trúc plugin của IDE.
- **Prompt mẫu để bạn dán cho Step `M0-S1`:**
  ```text

  Hãy thực hiện đúng Step M0-S1 theo docs/plan/M0.md, xuất đầy đủ các file trong khối # MANIFEST.
  ```
