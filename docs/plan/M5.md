# MILESTONE 5 (M5): TÌM KIẾM TỔNG HỢP (UC 3.10), CÀI ĐẶT, SAO LƯU JSON & KIỂM THỬ TỔNG THỂ

Mục tiêu của Milestone 5 là hoàn thiện 2 màn hình cuối cùng (`SearchActivity` cho UC 3.10 và `SettingsActivity` cho Dark Mode, Đa ngôn ngữ Việt/Anh, Sao lưu/Khôi phục JSON qua SAF), kèm rà soát R8/ProGuard và bộ kiểm thử tổng thể trước khi đóng gói nộp bài.

---

## STEP M5-S1: Màn hình Tìm kiếm Tổng hợp Công việc & Ghi chú (`SearchActivity` - UC 3.10)

- **Mục tiêu 1 câu:** Xây dựng màn hình `SearchActivity` cho phép người dùng nhập từ khóa và xem đồng thời kết quả tìm kiếm của cả Công việc lẫn Ghi chú nhanh trên cùng một màn hình (khớp tuyệt đối UC 3.10), hỗ trợ lọc nhanh theo Chip (`Tất cả`, `Công việc`, `Ghi chú`) và mở xem/sửa chi tiết khi chọn kết quả.
- **Step phụ thuộc:** `M4-S2`
- **Chế độ khuyến nghị:** **Chat thường** hoặc **Tasks**.
- **File cần gom để đính kèm:**
  ```bash
  python gop_code.py app/src/main/AndroidManifest.xml app/src/main/java/com/vinhnt/todonotes/ui/main/MainActivity.java app/src/main/java/com/vinhnt/todonotes/data/repository/TaskRepository.java app/src/main/java/com/vinhnt/todonotes/data/repository/NoteRepository.java app/src/main/java/com/vinhnt/todonotes/ui/tasks/TaskAdapter.java app/src/main/java/com/vinhnt/todonotes/ui/notes/NoteAdapter.java app/src/main/res/values/strings.xml
  ```
- **File sẽ tạo/sửa (5 file):**
    - `app/src/main/AndroidManifest.xml` (đăng ký `SearchActivity`)
    - `app/src/main/res/layout/activity_search.xml`
    - `app/src/main/java/com/vinhnt/todonotes/ui/search/SearchViewModel.java`
    - `app/src/main/java/com/vinhnt/todonotes/ui/search/SearchActivity.java`
    - `app/src/main/java/com/vinhnt/todonotes/ui/main/MainActivity.java` (kết nối nút Tìm kiếm trên Toolbar mở `SearchActivity`)
- **Tiêu chí nghiệm thu (Given / When / Then):**
    - **Given:** Trong cơ sở dữ liệu đang có cả Công việc và Ghi chú chứa từ khóa `"Android"`.
    - **When:**
        1. Bấm biểu tượng Tìm kiếm trên Toolbar của `MainActivity` -> Mở `SearchActivity`, bàn phím tự động bật lên (UC 3.10 bước 1).
        2. Nhập từ khóa `"Android"` -> Màn hình hiển thị cả danh sách Công việc và danh sách Ghi chú khớp từ khóa (UC 3.10 bước 2 & 3).
        3. Bấm vào 1 công việc hoặc 1 ghi chú trong kết quả -> Mở màn hình chi tiết tương ứng (UC 3.10 bước 4).
        4. Nhập từ khóa không tồn tại `"xyz123"` -> Hiển thị thông báo không tìm thấy kết quả phù hợp (UC 3.10 rẽ nhánh 2).
        5. Xóa trắng từ khóa (UC 3.10 rẽ nhánh 1) -> Hiển thị lại danh sách mặc định.
    - **Then:** Đáp ứng chính xác 100% từng bước của UC 3.10.
- **Cách kiểm thử:**
    - Lệnh Gradle:
      ```bash
      .\gradlew.bat assembleDebug
      .\gradlew.bat testDebugUnitTest
      ```
    - Checklist thủ công trên máy ảo Pixel 7:
        1. Tìm kiếm từ khóa có dấu và không dấu, kiểm tra tốc độ phản hồi tức thì.
        2. Bấm tích hoàn thành công việc hoặc mở sửa ghi chú ngay từ kết quả tìm kiếm, quay lại kiểm tra kết quả cập nhật đúng.
- **Rủi ro & Điều dễ sai:**
    - Khi người dùng sửa hoặc xóa một mục từ màn hình chi tiết rồi quay lại `SearchActivity`, danh sách kết quả tìm kiếm phải tự động cập nhật nhờ `LiveData` mà không cần gõ lại từ khóa.
- **Prompt mẫu để bạn dán cho Step `M5-S1`:**
  ```text
  OK Step M5-S1.
  Tôi đính kèm AGENTS.md, docs/SPEC.md và tat_ca_code_cu.txt.
  Hãy thực hiện đúng Step M5-S1 theo docs/plan/M5.md để xây dựng SearchActivity và SearchViewModel đáp ứng UC 3.10.
  ```
- **Commit message gợi ý:** `feat(search): implement unified SearchActivity for tasks and quick notes (UC 3.10)`

## STEP M5-S2: Màn hình Cài đặt (`SettingsActivity`), Sao lưu / Khôi phục JSON (`BackupRepository`), R8/ProGuard & Kiểm thử tổng thể

- **Mục tiêu 1 câu:** Xây dựng màn hình `SettingsActivity` hỗ trợ đổi Giao diện Sáng/Tối/Hệ thống, đổi Ngôn ngữ Tiếng Việt/Tiếng Anh (`AppCompatDelegate.setApplicationLocales`), Sao lưu & Khôi phục toàn bộ dữ liệu ra file `.json` qua Storage Access Framework (`BackupRepository`), kèm Unit Test cho Backup JSON và cấu hình hoàn chỉnh ProGuard/R8.
- **Step phụ thuộc:** `M5-S1`
- **Chế độ khuyến nghị:** **Chat thường**.
- **File cần gom để đính kèm:**
  ```bash
  python gop_code.py app/src/main/AndroidManifest.xml app/proguard-rules.pro app/src/main/java/com/vinhnt/todonotes/TodoNotesApp.java app/src/main/java/com/vinhnt/todonotes/util/PreferencesManager.java app/src/main/java/com/vinhnt/todonotes/data/local/AppDatabase.java app/src/main/java/com/vinhnt/todonotes/data/local/dao/TaskDao.java app/src/main/java/com/vinhnt/todonotes/data/local/dao/NoteDao.java app/src/main/res/values/strings.xml app/src/main/res/values-en/strings.xml
  ```
- **File sẽ tạo/sửa (8 file):**
    - `app/src/main/AndroidManifest.xml` (đăng ký `SettingsActivity` và `LocaleConfig` nếu cần)
    - `app/proguard-rules.pro` (giữ nguyên Room Entities/DAOs khi bật R8 bản Release)
    - `app/src/main/res/xml/locales_config.xml`
    - `app/src/main/res/layout/activity_settings.xml`
    - `app/src/main/java/com/vinhnt/todonotes/data/repository/BackupRepository.java`
    - `app/src/main/java/com/vinhnt/todonotes/ui/settings/SettingsActivity.java`
    - `app/src/main/java/com/vinhnt/todonotes/data/local/dao/TaskDao.java` (bổ sung truy vấn đồng bộ lấy danh sách phục vụ Export JSON trên luồng nền)
    - `app/src/main/java/com/vinhnt/todonotes/data/local/dao/NoteDao.java` (bổ sung truy vấn đồng bộ lấy danh sách phục vụ Export JSON trên luồng nền)
    - `app/src/androidTest/java/com/vinhnt/todonotes/data/repository/BackupRestoreInstrumentedTest.java`
- **Tiêu chí nghiệm thu (Given / When / Then):**
    - **Given:** Người dùng mở `SettingsActivity` từ biểu tượng bánh răng trên `MainActivity`.
    - **When:**
        1. Chọn Giao diện Tối / Sáng -> Ứng dụng đổi giao diện ngay lập tức và lưu lại cho các lần mở sau.
        2. Chọn Ngôn ngữ Tiếng Anh / Tiếng Việt -> Toàn bộ chuỗi giao diện chuyển sang ngôn ngữ đã chọn.
        3. Bấm **"Xuất dữ liệu sao lưu (.json)"** -> Chọn nơi lưu trên máy ảo -> File `.json` được tạo thành công chứa toàn bộ Tasks & Notes.
        4. Xóa thử dữ liệu, sau đó bấm **"Khôi phục dữ liệu từ file (.json)"** và chọn file vừa xuất -> Toàn bộ Công việc, Ghi chú và các lịch nhắc nhở còn hạn ở tương lai được khôi phục đầy đủ.
    - **Then:** Chạy toàn bộ bộ kiểm thử `testDebugUnitTest`, `connectedDebugAndroidTest`, `lintDebug`, `assembleDebug` và `assembleRelease` đều thành công.
- **Cách kiểm thử:**
    - Lệnh Gradle tổng kết toàn dự án:
      ```bash
      .\gradlew.bat testDebugUnitTest
      .\gradlew.bat connectedDebugAndroidTest
      .\gradlew.bat lintDebug
      .\gradlew.bat assembleDebug
      ```
- **Rủi ro & Điều dễ sai:**
    - Khi Import dữ liệu từ file JSON bên ngoài, nếu file JSON bị hỏng hoặc không đúng cấu trúc của ứng dụng, phải bắt `JSONException` và lùi giao dịch (`runInTransaction`), tuyệt đối không được xóa dữ liệu hiện có trước khi kiểm tra file JSON hợp lệ.
